# Tropical Charters

Private boat charters from Fajardo, Puerto Rico. Bilingual (EN/ES) site built with Astro, GSAP and Lenis.

**Live preview:** https://jaredb650.github.io/tropicalCharters/

```sh
nvm use      # Node 22.12+
npm install
npm run dev  # http://localhost:4321/tropicalCharters/
```

- Content (trips, boats, copy, prices) lives in `src/data/` and `src/i18n/`.
- See [ARCHITECTURE.md](ARCHITECTURE.md) for the structure, the motion system, the cal.com booking plan and the pre-launch checklist.

Photos are Unsplash placeholders. Boats, prices, contact details and reviews are placeholders until the client supplies them.
